## 🎤 **VIVA PREPARATION**

### **Opening Statement:**
> "Good morning/afternoon. I'm presenting API ReplayLab, an automated regression testing platform for APIs. It helps developers detect when code changes break existing functionality before deployment."

### **Key Points to Emphasize:**

1. **Real-World Problem:**
   - "APIs can return 200 OK but have wrong data"
   - "Traditional tools miss business logic errors"

2. **Solution:**
   - "We capture expected behavior"
   - "Automatically test on every code change"
   - "Block deployment if critical issues found"

3. **Technology:**
   - "MERN stack - Modern, industry-standard"
   - "MongoDB Atlas - Cloud database"
   - "Jenkins - Professional CI/CD tool"
   - "Docker - Container orchestration"

4. **ASE Coverage:**
   - "Complete syllabus implementation"
   - "Every topic has practical application"
   - "Production-ready architecture"

### **Expected Questions:**

**Q: How does it detect regressions?**
**A:** "We use a deep comparison algorithm that examines every field in the JSON response. If any business-critical field changes (like price, total, status), we flag it as a regression and calculate the severity based on which fields changed."

**Q: What makes it better than Postman?**
**A:** "Postman is for manual testing. API ReplayLab is for automated regression detection in CI/CD. It runs automatically on every code commit and blocks deployment if issues are found. Postman requires someone to manually run tests."

**Q: How does Jenkins integration work?**
**A:** "When code is pushed to Git, Jenkins automatically triggers our pipeline. It builds the app, runs all tests, executes our replay tests, and if any critical regression is detected, it fails the build and prevents deployment."

**Q: What database do you use?**
**A:** "MongoDB Atlas, which is a cloud-hosted database. We chose it because it's NoSQL, flexible for JSON data, scales automatically, and doesn't require local installation."

**Q: Can you show the regression detection?**
**A:** [Open browser, go to Reports, show the Todo Item regression with diff]
